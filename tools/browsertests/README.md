# Browsertests (Playwright, Chromium)

Draaien tegen een lokale webserver met de inhoud van de repo (`public\` in de OneDrive-map) op poort 8765:

    cd public && python -m http.server 8765
    python demo-flow.py            # startscherm, starterset, autosave, labels, Settings, herbezoek, server, reset, opzoeklinks (42 controles)
    python migratie-en-file.py     # bestaand token zonder serverUrl -> data.php; geen token in de HTML; file:// -> bestandsmodus
    python opslagbalk.py           # balk bij niet-persistente browseropslag, tekstvarianten (Firefox, iOS, Dock-app), sluiten, sessie (21 controles)
    python formulair-import.py     # DataModel.sqlite inlezen, download vergelijken met formulair-naar-json.py (pad SQ aanpassen)
    python formulair-doorsturen.py # "Add to miFormulas" in een lege browser -> app start met 698 formules (pad SQ aanpassen)
    python merge-import.py         # Formulair-import samengevoegd met bestaande data: naam-matching, diluties, categorieën, overslaan bij tweede import, Undo, lege browser (21 controles)
    python site-reopen.py          # Open data file… op de site: onthouden, Reopen, Forget in Settings, verdwenen bestand, Install-knop, Save to a data file… (36 controles)
    python file-mode.py            # gedownloade app via file://: hint, starterset van miformulas.com (nagebootst), databestand aanmaken (44 controles, incl. herstart met Reopen en verdwenen bestand; geen webserver nodig; leest de bouwstempel uit index.html)
    python help.py                 # Help-knop: ingebedde handleiding, inhoudstafel, terug naar de vorige weergave (17 controles)
    python move-into.py            # Move into…: elke formule met één versie als versie van een andere, Move together, "this formula", een eigen formule die niet bevroren binnenkomt, Undo (47 controles)
    python materiaallijst.py       # materials library: import, Settings, Get the latest library, + New material met feiten, Browse the library… met shift-klik, "+ Add" in de zoeklijst naast en zonder eigen treffers, een rommelige lijst (dubbels, gedeelde alias, waarden buiten bereik), Undo (66 controles)
    python deel-formule.py        # Share this version…: wat er in het bestand komt en wat er niet in komt (solventvlag, label, volgorde, decimalen, lege versie, verweesde regel), en de rondgang bij een ontvanger die het materiaal, het solvent en de formule niet heeft (40 controles)
    python export-bibliotheek.py   # Export my inventory as a library…: alles vooraf aangevinkt, shift-klik, wat er wel en niet in het bestand komt, en de rondgang terug via import (40 controles)
    python import-controle.py      # Import formula… als poort: regel zonder naam, onleesbaar of negatief gewicht, dilutie buiten 0-100 blokkeren Confirm; komma, percentteken en ontbrekende dilutie hersteld; solventvlag; Undo neemt formule, materiaal, bestelregel en categorieën terug (27 controles)
    python opruiming.py            # staart van de review: zoeken op "starter", bevestiging bij ✕, ellipsis op de openers, aliassen in de keuzelijst, attributie in Settings, alleen-lezen op een telefoon (34 controles)
    python undo-navigatie.py       # één undo-stap per handeling (nieuwe categorie, predilutie, Replace + dilutiewissel, ook door de dilutiedialoog), Redo keert terug naar de plek van de wijziging, Copy vanuit een oudere versie, bench mee naar een nieuwe versie (18 controles)
    python validatie.py            # wat de app weigert: negatief gewicht, dilutie buiten 0-100, dubbele dilutie, basisdilutie die verdwijnt, tekst als getal, eigen velden met underscore, negatief doelgewicht, basisdilutie boven 100 in + New material, Set EtOH zonder ethanol; dagsnapshot, Delete version op een import, verborgen importverwijzing (25 controles)
    python namen.py                # Add line, formule-import en Delivered nemen de feiten uit de bibliotheek mee, categorie niet dubbel door hoofdletters, alias die je al bezit, hernoemen zonder dubbele namen (14 controles)
    python kost-en-ifra.py         # kost per gram zuiver (Delivered met basisdilutie, predilutie met hoeveelheid en IFRA-veld), IFRA 0 = prohibited en negatief = niet nagekeken, geen databestand openen, bibliotheek met rommel, server zonder databestand (22 controles)
    python geen-variaties.py       # sinds 260915b geen variaties meer: een oud bestand met variaties laadt met één waarschuwing en houdt het veld, formulepagina, Move into…, Copy, Compare, Welcome-tegel, export en lijstteller kennen alleen versies (15 controles)
    python opslagvolgorde.py       # één schrijfactie tegelijk: wijziging tijdens een trage PUT (nagebootste server in de pagina), geen tweede PUT met dezelfde ETag, browseropslag die weigert, databestand vervangt de browserkopie; dagsnapshot bij onbereikbare server wordt niet over de serverdata geschreven, mislukte eerste schrijfactie naar een bestand (28 controles)
    python getalnotatie.py         # en-GB: duizendtalscheiding in invoervelden, parseNum, Delivered per 1000 g, IFRA-dosering per formule, Ctrl+Z onder een dialoog, Replace + Cancel, gebruiksindex na Add line; de getalvelden van de materiaalpagina en het veldrooster (21 controles)
    python uiterlijk.py           # uitvoer en uiterlijk: CSV met het scheidingsteken en de decimaal van de taal, cellen die met = beginnen, bestandsnaam met een schuine streep, witte achtergrond bij afdrukken, zachte rode kleur in beide thema's, koptekst op één regel bij 1280 px, labels aan hun veld, lijstregels met het toetsenbord, koptekst op 850 px, de kop van een formule, de koptekst op 1440/1280/1024/850 px met tikdoelen en de statusregel (44 controles)
    python koptekst-en-focus.py    # de focus blijft in de gewichtskolom (Tab, Shift+Tab, Enter), de bench view past op 1280 px, de telefoon zonder doodlopende wegen (☰, To order), contrast van de amberkleurige tekst in beide thema's (19 controles)
    python leeg-en-welcome.py      # Start empty op het startscherm, het blok Start here met één primaire knop, geen Recently edited zonder eigen werk, de kolom Cost pas met een prijs, een kaal databestand dat + New formula en + New material niet laat crashen (16 controles)
    python materialen-csv.py       # materialen uit een CSV: de rondgang met de eigen CSV-uitvoer (basis eerst), een vreemd blad met ; en decimale komma en synoniemen als kopnamen, een Windows-1252-bestand, dubbels en rijen zonder naam, het sjabloon, één undo-stap; Get the latest library in het CSV-venster en het Import/Export-venster van 260916d (67 controles)
    python formules-uitvoer.py     # alle formules naar één bestand en weer terug: de uitvoer draagt versies, labels en notities maar geen labogegevens en geen materialId, de voorvertoning vat samen, de materialen komen als "to order" zonder de bestellijst te vullen, alles in één undo-stap, een tweede invoer geeft "(import)" en een onleesbare regel blokkeert Confirm (37 controles)
    python formules-csv.py         # formules uit een CSV: de rondgang van Export all formulas (Excel) met de elfde kolom Notes en zes decimalen voor een spoorregel, een blad zonder Formula-kolom (bestandsnaam als formule, "v3 45gr" wordt het label), een vreemd blad met ; en decimale komma en synoniemen, de Total-regel als gewichtscontrole, een onleesbaar gewicht dat Confirm blokkeert, een materialenblad dat geweigerd wordt (53 controles)
    python terug-en-vooruit.py     # terug en vooruit via de geschiedenis van de browser: elke plaats is een stap, de versie komt mee, de handleiding telt mee, een verwijderd item wordt overgeslagen, een herlaadbeurt landt op dezelfde plek, en de geïnstalleerde app toont twee knoppen die aan de uiteinden uitgaan (22 controles; Playwright kan de zijknoppen van een muis niet sturen, go_back/go_forward doen hetzelfde)
    python lijst-en-navigatie.py   # de zoekterm hoort bij de lijst (Formulas, Materials, To order) en blijft niet staan bij het wisselen; een ander item begint bovenaan in het paneel, terwijl een re-render van dezelfde pagina de leespositie houdt, ook in de handleiding (24 controles)
    python instellingen.py         # Settings: de servervelden staan er op de site en niet in de gedownloade app (met de hint die de weg wijst), en Open where you left off onthoudt tabblad, formule of materiaal en versie per toestel, herstelt ze bij de start, slaat een verdwenen formule over en wist alles zodra je het uitzet (37 controles)
    python robuustheid.py          # wat de app moet overleven: databestand met gaten en dubbele id's, een host die elke url met html beantwoordt, een onleesbare browserkopie, tekst in een getalveld; Enter in een dialoog, Tab vanaf het startscherm (inert), klikbare elementen met het toetsenbord, Undo terug naar de wijziging (20 controles)
    python safari-hints.py         # Safari op de Mac: Add to Dock-link en dialoog, waarschuwing bij Download the app, alleen-lezen startscherm via file://, opslagbalk in tabblad en Dock-app, Import from Formulair op de Welcome-pagina, importer in de Dock-app (37 controles)
    python screenshots.py          # geen test: maakt de app-schermen voor docs/img (zie docstring)

Vereist `pip install playwright` en `playwright install chromium`. De paden bovenaan de
scripts (URL, SQ, referentiebestand) zijn die van de cloudsessie van 07/09/2026; pas ze aan.
