# Browsertests (Playwright, Chromium)

Draaien tegen een lokale webserver met de inhoud van de repo (`public\` in de OneDrive-map) op poort 8765:

    cd public && python -m http.server 8765
    python demo-flow.py            # startscherm, starterset, autosave, labels, Settings, herbezoek, server, reset, opzoeklinks (42 controles)
    python migratie-en-file.py     # bestaand token zonder serverUrl -> data.php; geen token in de HTML; file:// -> bestandsmodus; data.php ook zonder IndexedDB
    python opslagbalk.py           # balk bij niet-persistente browseropslag, tekstvarianten (Firefox, iOS, Dock-app), sluiten, sessie (21 controles)
    python formulair-import.py     # DataModel.sqlite inlezen, download vergelijken met formulair-naar-json.py (pad SQ aanpassen)
    python formulair-doorsturen.py # "Add to miFormulas" in een lege browser -> app start met 698 formules (pad SQ aanpassen)
    python merge-import.py         # Formulair-import samengevoegd met bestaande data: naam-matching, diluties, categorieën, overslaan bij tweede import, Undo, lege browser (21 controles)
    python site-reopen.py          # Open data file… op de site: onthouden, Reopen, Forget in Settings, verdwenen bestand (ook met toestemming granted), Install-knop, Save to a data file… (40 controles)
    python file-mode.py            # gedownloade app via file://: hint, starterset van miformulas.com (nagebootst), databestand aanmaken (44 controles, incl. herstart met Reopen en verdwenen bestand; geen webserver nodig; leest de bouwstempel uit index.html)
    python help.py                 # Help-knop: ingebedde handleiding, inhoudstafel, terug naar de vorige weergave, en de handleiding die elke knop noemt zoals de app hem labelt, weglatingsteken inbegrepen (20 controles)
    python move-into.py            # Move into…: elke formule met één versie als versie van een andere, Move together, "this formula", een eigen formule die niet bevroren binnenkomt, Undo, alleen de verplaatste formules verdwijnen uit de lijst, en prepared en hideSource gaan mee (52 controles)
    python materiaallijst.py       # materials library: import, Settings, Get the latest library, + New material met feiten, Browse the library… met shift-klik, "+ Add" in de zoeklijst naast en zonder eigen treffers, een rommelige lijst (dubbels, gedeelde alias, waarden buiten bereik), Undo, en accenten en de ligatuur œ die zoeken en opzoeken niet meer in de weg staan (72 controles)
    python deel-formule.py        # Share this version…: wat er in het bestand komt en wat er niet in komt (solventvlag, label, volgorde, decimalen, lege versie, verweesde regel), en de rondgang bij een ontvanger die het materiaal, het solvent en de formule niet heeft (40 controles)
    python export-bibliotheek.py   # Export my inventory as a library…: alles vooraf aangevinkt, shift-klik, wat er wel en niet in het bestand komt, en de rondgang terug via import (40 controles)
    python import-controle.py      # Import formula… als poort: regel zonder naam, onleesbaar of negatief gewicht, dilutie buiten 0-100 blokkeren Confirm; komma, percentteken en ontbrekende dilutie hersteld; solventvlag; Undo neemt formule, materiaal, bestelregel en categorieën terug; een naam die twee keer nieuw is wordt één materiaal, regels die geen regel zijn worden geweigerd in plaats van te crashen, en een oneindig gewicht komt er niet door (34 controles)
    python opruiming.py            # staart van de review: zoeken op "starter", bevestiging bij ✕, ellipsis op de openers, aliassen in de keuzelijst, attributie in Settings, alleen-lezen op een telefoon, een lege lijst die uitlegt waarom, een bestelregel die geen knop is, dubbelklik op + New version, de namen van de aankruisvakjes, een materiaal dat alleen in een oudere versie zit, Delete version, de zoekknop die geen winkels belooft die je niet hebt en een gebruikslijst die zegt dat ze afgekapt is; de staart van de vierde audit: Compare vanaf de eerste versie, Close compare terug in de bench, Ctrl+P in Compare, de kolom Cost op de afdruk, de dubbele regels in beide weergaven en Copy met notities en proeflog (74 controles)
    python undo-navigatie.py       # één undo-stap per handeling (nieuwe categorie, predilutie, Replace + dilutiewissel, ook door de dilutiedialoog), Redo keert terug naar de plek van de wijziging, een categoriewissel die een categorie aanmaakt, Copy vanuit een oudere versie, bench mee naar een nieuwe versie, een bench-groep die zijn eigen regel vasthoudt en Ctrl+P zonder printknop (27 controles)
    python validatie.py            # wat de app weigert: negatief gewicht, dilutie buiten 0-100, dubbele dilutie, basisdilutie die verdwijnt, tekst als getal, eigen velden met underscore, negatief doelgewicht, basisdilutie boven 100 in + New material, Set EtOH zonder ethanol; dagsnapshot, Delete version op een import, verborgen importverwijzing (25 controles)
    python namen.py                # Add line, formule-import en Delivered nemen de feiten uit de bibliotheek mee, categorie niet dubbel door hoofdletters, alias die je al bezit, hernoemen zonder dubbele namen, een alias die meteen meetelt, hernoemen naar andermans alias, dezelfde stof twee keer op dezelfde dilutie, een nieuwe formule die in Uncategorised vertrekt en de kleurkiezer per categorie, die #FFFFFF net als de lijsten als grijs leest (70 controles)
    python kost-en-ifra.py         # kost per gram zuiver (Delivered met basisdilutie, predilutie met hoeveelheid en IFRA-veld), de kleinste regel in gram in de voorbeschouwing, IFRA 0 = prohibited en negatief = niet nagekeken, de IFRA-dosering op de volledige inhoud met het solvent in dezelfde tabel, een regel naar een gewist materiaal, een kopje dat niets vrijgeeft, Deduct base met een basisdilutie en de laatste dilutie die blijft staan, geen databestand openen, bibliotheek met rommel, server zonder databestand, en Delivered dat vraagt of de oude voorraad op is (58 controles)
    python geen-variaties.py       # sinds 260915b geen variaties meer: een oud bestand met variaties laadt met één waarschuwing en houdt het veld, formulepagina, Move into…, Copy, Compare, Welcome-tegel, export en lijstteller kennen alleen versies (15 controles)
    python opslagvolgorde.py       # één schrijfactie tegelijk: wijziging tijdens een trage PUT (nagebootste server in de pagina), geen tweede PUT met dezelfde ETag, browseropslag die weigert, databestand vervangt de browserkopie; dagsnapshot bij onbereikbare server wordt niet over de serverdata geschreven, mislukte eerste schrijfactie naar een bestand; een lege server waar je je eigen Backup binnenbrengt zonder bestandsverwijzing (69 controles)
    python getalnotatie.py         # en-GB: duizendtalscheiding in invoervelden, parseNum, Delivered per 1000 g en Amount purchased met een eenheid (ml met density), IFRA-dosering per formule, Ctrl+Z onder een dialoog, Replace + Cancel, Escape op het dilutievenster, gebruiksindex na Add line; de getalvelden van de materiaalpagina, het veldrooster en een spoordilutie die niet als 0 % leest (36 controles)
    python uiterlijk.py           # uitvoer en uiterlijk: CSV met het scheidingsteken en de decimaal van de taal, cellen die met = beginnen, bestandsnaam met een schuine streep, witte achtergrond bij afdrukken, zachte rode kleur in beide thema's, koptekst op één regel bij 1280 px, labels aan hun veld, lijstregels met het toetsenbord, koptekst op 850 px, de kop van een formule, de koptekst op 1440/1280/1024/850 px met tikdoelen en de statusregel (44 controles)
    python koptekst-en-focus.py    # de focus blijft in de gewichtskolom (Tab, Shift+Tab, Enter), de bench view past op 1280 px, de telefoon zonder doodlopende wegen (☰, To order), contrast van de amberkleurige tekst in beide thema's, de bench view die niet schrijft in de alleen-lezenstand, --muted dat overal AA haalt, de opslagstand op haar eigen ondergrond, wat alleen-lezen laat staan en een bench die daar niet sleepbaar is (57 controles)
    python leeg-en-welcome.py      # Start empty op het startscherm, het blok Start here met één primaire knop, geen Recently edited zonder eigen werk, de kolom Cost pas met een prijs, een kaal databestand dat + New formula en + New material niet laat crashen (16 controles)
    python materialen-csv.py       # materialen uit een CSV: de rondgang met de eigen CSV-uitvoer (basis eerst), een vreemd blad met ; en decimale komma en synoniemen als kopnamen, een Windows-1252-bestand, dubbels en rijen zonder naam, het sjabloon, één undo-stap; Get the latest library in het CSV-venster en het Import/Export-venster van 260916d; aliassen die aanvullen in plaats van wissen, negatieve prijs en dichtheid, een BOM bij de terugval naar windows-1252, een formulesblad dat geweigerd wordt, lege uitvoer die dat zegt en een lege Solvent-cel die de bibliotheek laat staan (77 controles)
    python formules-uitvoer.py     # alle formules naar één bestand en weer terug: de uitvoer draagt versies, labels en notities maar geen labogegevens en geen materialId, de voorvertoning vat samen, de materialen komen als "to order" zonder de bestellijst te vullen, alles in één undo-stap, een tweede invoer geeft "(import)" en een onleesbare regel blokkeert Confirm, en een regel naar een gewist materiaal valt uit beide Excel-uitvoeren (42 controles)
    python formules-csv.py         # formules uit een CSV: de rondgang van Export all formulas (Excel) met de elfde kolom Notes en zes decimalen voor een spoorregel, een blad zonder Formula-kolom (bestandsnaam als formule, "v3 45gr" wordt het label), een vreemd blad met ; en decimale komma en synoniemen, de Total-regel als gewichtscontrole, een onleesbaar gewicht dat Confirm blokkeert, een materialenblad dat geweigerd wordt, een Total-regel met een dilutie, een label dat niet doorloopt en de datum uit het blad (60 controles)
    python terug-en-vooruit.py     # terug en vooruit via de geschiedenis van de browser: elke plaats is een stap, de versie komt mee, de handleiding telt mee, een verwijderd item wordt overgeslagen, een herlaadbeurt landt op dezelfde plek, de geïnstalleerde app toont twee knoppen die aan de uiteinden uitgaan, en van versie wisselen is zelf een stap (26 controles; Playwright kan de zijknoppen van een muis niet sturen, go_back/go_forward doen hetzelfde)
    python lijst-en-navigatie.py   # de zoekterm hoort bij de lijst (Formulas, Materials, To order) en blijft niet staan bij het wisselen; een ander item begint bovenaan in het paneel, terwijl een re-render van dezelfde pagina de leespositie houdt, ook in de handleiding (24 controles)
    python instellingen.py         # Settings: de servervelden staan er op de site en niet in de gedownloade app (met de hint die de weg wijst), en Open where you left off onthoudt tabblad, formule of materiaal en versie per toestel, herstelt ze bij de start, slaat een verdwenen formule over en wist alles zodra je het uitzet (37 controles)
    python robuustheid.py          # wat de app moet overleven: databestand met gaten en dubbele id's, een host die elke url met html beantwoordt, een onleesbare browserkopie, tekst in een getalveld; Enter in een dialoog (één keer, ook na vijf openingen), Tab vanaf het startscherm (inert), klikbare elementen met het toetsenbord, Undo terug naar de wijziging (22 controles)
    python safari-hints.py         # Safari op de Mac: Add to Dock-link en dialoog, waarschuwing bij Download the app, alleen-lezen startscherm via file://, opslagbalk in tabblad en Dock-app, Import from Formulair op de Welcome-pagina, importer in de Dock-app, dagsnapshot op het alleen-lezen startscherm (40 controles)
    python screenshots.py          # geen test: maakt de app-schermen voor docs/img (zie docstring)

`python tools/controleer-bench.js <app.html> <data.json>` zegt of de bench-schikkingen van een databestand de overstap van bouw 260918d overleven (het verandert niets).

scripts (URL, SQ, referentiebestand) zijn die van de cloudsessie van 07/09/2026; pas ze aan.
